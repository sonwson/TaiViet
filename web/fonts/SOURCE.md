# Noto Sans Tai Viet

Unmodified font and SIL Open Font License downloaded from Google Fonts on 2026-09-06.

- https://github.com/google/fonts/tree/main/ofl/notosanstaiviet
- Font: `NotoSansTaiViet-Regular.ttf`
- License text: `OFL.txt`

The app serves this font locally, without requests to a third-party font CDN.

## Tai Viet Times

`tvtimes.ttf` was supplied by the project owner and copied unchanged from the project root. It is the preferred font for Tai Viet characters (U+AA80–U+AADF); Noto Sans Tai Viet remains a fallback. Vietnamese interface text keeps the existing system font.
